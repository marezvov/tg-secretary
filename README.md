# TG Secretary (v1.1 Production-Ready)
> Универсальный персональный ИИ-секретарь в Telegram с локальной LLM/VLM, голосовым распознаванием на CPU, управлением задачами и расписанием, чтением документов и веб-страниц.

Секретарь работает на **Python 3.11+**, фреймворке **aiogram 3** (Long Polling — не требует белого IP, проброса портов и вебхуков) и подключается к любому **OpenAI-совместимому серверу** (LM Studio, Ollama, vLLM, llama.cpp, LocalAI или облачным провайдерам).

---

## 🌟 Ключевые возможности

1. **Inbox со склейкой пакетов (1.8 секунды debounce):**
   * Все входящие сообщения, альбомы и пересылки склеиваются в один запрос к модели.
   * **Принцип Capture First:** сообщение сначала гарантированно фиксируется в SQLite `inbox_log`; при сбоях модели ничего не теряется и доступно для повтора кнопкой.
2. **Мультимодальность:**
   * **Голос:** локальное CPU-распознавание через `faster-whisper` (`int8`, `vad_filter=True`) — **0 МБ VRAM**; ленивая загрузка весов и автовыгрузка из оперативной памяти через 15 минут простоя.
   * **Фото и скриншоты:** сжатие до 1280 px (JPEG q85) и отправка в VLM (разбор афиш, олимпиад, расписаний, страниц учебников).
   * **Документы:** извлечение текста из `.pdf`, `.docx`, `.txt`, `.md`, автоматическая индексация в полнотекстовый поиск SQLite FTS5 и генерация выжимки.
   * **Ссылки:** Level 1 Playwright-экстрактор (`trafilatura` + PDF) и Level 2 визуальная навигация Set-of-Mark (SoM).
3. **Ход выполнения задач в реальном времени (Live Progress Tracking):**
   * При разборе цепочки шагов (открытие веб-ссылок, расшифровка аудиозаписей, извлечение документов, обращение к LLM/VLM, сохранение в календарь) бот показывает интерактивный живой статус, что именно выполняется в данную секунду.
   * **Гибкая настройка прямо в Telegram (`/settings → ⚡️ Ход выполнения`):**
     * Режимы: **Подробный** (пошаговый лог с галочками), **Компактный** (однострочный статус), **Выключен** (тихий режим).
     * Гранулярные тумблеры: 🌐 Ссылки/браузер, 🎧 Аудио/Whisper, 📄 Документы, 🧠 Запросы к нейросети, 📅 Календарь.
4. **Мониторинг сервера и моделей (`/status`):**
   * **Оборудование ПК:** операционная система, архитектура, хост, ядра CPU, оперативная память RAM (занято / всего / процент), место на диске, размер SQLite базы данных, аптайм бота и аптайм хоста. Работает без внешних зависимостей на Linux, Windows и macOS (через `ctypes` и `/proc`), с автоподдержкой `psutil`.
   * **Нейросети и модели:** проверка связи с LLM эндпоинтом, пинг в миллисекундах (`🟢 Онлайн (45 мс)`), проверка активной модели, список доступных на сервере моделей, статус VLM (Vision), состояние Whisper STT (загружен в RAM или выгружен), очередь тяжёлых задач и статус фонового планировщика.
   * Кнопка **[🔄 Обновить]** для мгновенной перепроверки в один клик.
5. **Управление задачами и закрытыми делами (Архив задач):**
   * Фильтрация задач: **Активные**, **Сегодня**, **Просроченные**, **Выполненные**, **Замороженные**, **Все закрытые**.
   * Команда **/closed** (или **/done**) — мгновенный просмотр закрытых задач с точным временем закрытия и относительным сроком («Закрыта: 23.11 14:30 · 2 ч назад»).
   * Поиск по задачам: `/tasks [фильтр] [запрос]`, `/closed [запрос]` или кнопка **[🔍 Поиск]**.
   * Возможность **вернуть задачу в работу** (`[♻️ Вернуть в работу]`) или **повторить/клонировать** её (`[📋 Повторить задачу]`) для создания нового активного дела по шаблону выполненного.
   * Автоматическая раскладка задач по свободным окнам с учётом уровней энергии и режима дня.
4. **Календарь и сетка недели:**
   * **/schedule_edit** — просмотр сетки занятий, добавление/удаление слотов, массовый импорт по фото/тексту/голосу с предварительным превью.
   * **Пауза расписания:** временное отключение сетки (каникулы, болезнь) до выбранной даты без удаления записей.
   * Расчёт свободных окон дня за вычетом буферов на дорогу и мероприятий.
5. **Анти-ступор (`/now`):**
   * Выбор текущего состояния (`🟢 Голова варит`, `🟡 Устал`, `🔴 Нет сил`) и выдача ровно 1 задачи с конкретным первым шагом на 10–15 минут и таймером.
6. **Мониторинг страниц (`/watch <url> <цель>`):**
   * Периодическая проверка SHA-256 хэша; при изменении модель сверяет смысл с целью и присылает уведомление только при релевантных изменениях.
7. **Архив и статистика:**
   * **/archive** — архив выполненных и замороженных дел, прошедших событий, заметок, поиск в архиве и мягкая очистка задач старше 30 дней.
   * **/stats** — статистика выполненных дел (за день, за 7 дней, за 30 дней, за всё время), разбивка по категориям и продуктивности.
8. **Питание ПК (`rtcwake`, опционально для Linux):**
   * Защита от зацикливания сна, окно 15 минут, уведомление за 5 минут с кнопками `[⏸ Отложить на 1 час]` и `[🚫 Отменить на сегодня]`.

## 🚀 Варианты развёртывания

### Способ 1. Docker & Docker Compose (Рекомендуется — Zero-Config для любых машин)

Этот способ изолирует все зависимости (включая Chromium для Playwright и библиотеки для Whisper), гарантирует одинаковую работу на **Ubuntu Linux**, **Windows (Docker Desktop)** и **macOS**.

1. Клонируй репозиторий:
   ```bash
   git clone <REPO_URL> tg-secretary
   cd tg-secretary
   ```
2. Создай `.env` из примера:
   ```bash
   cp .env.example .env
   ```
   Укажи свой `BOT_TOKEN` и URL локальной LLM (для обращения к хосту из контейнера используй `http://host.docker.internal:11434/v1` для Ollama или `http://host.docker.internal:1234/v1` для LM Studio).

3. Запусти сборку и контейнер:
   ```bash
   docker compose up -d --build
   ```

4. Просмотр логов:
   ```bash
   docker compose logs -f
   ```

### Способ 2. Linux (Ubuntu / Debian / Arch / Fedora) — venv + systemd

#### 1. Подготовка окружения
```bash
# Ubuntu / Debian
sudo apt update
sudo apt install -y python3 python3-venv python3-pip ffmpeg libgomp1

cd tg-secretary
python3 -m venv .venv
source .venv/bin/activate
pip install --upgrade pip
pip install -r requirements.txt

# Установка безголового Chromium для парсинга и SoM-навигатора
playwright install chromium
playwright install-deps chromium
```

#### 2. Настройка `.env`
```bash
cp .env.example .env
nano .env
```
Заполни:
```dotenv
BOT_TOKEN=123456789:ABCdefGhIJKlmNoPQRsTUVwxyZ
LLM_BASE_URL=http://127.0.0.1:8000/v1
LLM_MODEL_NAME=Qwen2.5-32B-Instruct
LLM_API_KEY=sk-local
```

#### 3. Настройка питания через rtcwake (опционально)
Если планируешь засыпание и пробуждение ПК по расписанию:
```bash
sudo visudo -f /etc/sudoers.d/tg-secretary
```
Добавь строку (замени `<user>` на своего пользователя):
```text
<user> ALL=(root) NOPASSWD: /usr/sbin/rtcwake
```
Проверь права:
```bash
sudo chmod 440 /etc/sudoers.d/tg-secretary
sudo -n /usr/sbin/rtcwake --version
```
В `.env` для реального выключения переключи `POWER_DRY_RUN=false`.

#### 4. Запуск в виде systemd-сервиса
Отредактируй `tg-secretary.service`, указав своего пользователя и пути:
```ini
[Unit]
Description=Personal AI Secretary Telegram Bot
After=network-online.target
Wants=network-online.target

[Service]
Type=simple
User=YOUR_USER
WorkingDirectory=/home/YOUR_USER/tg-secretary
Environment=PYTHONUNBUFFERED=1
ExecStart=/home/YOUR_USER/tg-secretary/.venv/bin/python -m app.main
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
```

Активируй службу:
```bash
sudo cp tg-secretary.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable --now tg-secretary
sudo systemctl status tg-secretary
journalctl -u tg-secretary -f
```

## 🧠 Подключение локальных моделей

Бот обращается к стандартному OpenAI Chat Completions API (`/v1/chat/completions`) и эндпоинту `/v1/models` для проверки готовности модели при старте.

### 1. LM Studio
1. Загрузи модель (например, `Qwen 2.5 32B/7B Instruct` или `Qwen 2.5 VL` для поддержки фото).

3. Запусти сервер на порту `1234`.
4. В `.env`:
   ```dotenv
   LLM_BASE_URL=http://127.0.0.1:1234/v1
   LLM_MODEL_NAME=qwen2.5-32b-instruct
   ```

### 2. Ollama
1. Запусти модель: `ollama run qwen2.5:32b` (или `minicpm-v` / `llama3.2-vision` для фото).
2. В `.env`:
   ```dotenv
   LLM_BASE_URL=http://127.0.0.1:11434/v1
   LLM_MODEL_NAME=qwen2.5:32b
   ```

### 3. vLLM
```bash
vllm serve Qwen/Qwen2.5-32B-Instruct --port 8000 --max-model-len 16384 --chat-template ...
```


## 📋 Справочник команд бота

### Планирование и задачи
* `/today [дата]` — карточка дня: погода, почасовая сетка, мероприятия, задачи на день и свободные окна.
* `/week` — сводка на 7 дней со светофором нагрузки (`🟥`/`🟨`/`🟩`) и балансом свободного времени.
* `/tasks [фильтр] [поиск]` — менеджер задач:
  * фильтры: `active`, `today`, `overdue`, `done`, `frozen`, `closed`, `all`.
  * примеры: `/tasks done`, `/tasks физика`, `/tasks closed проект`.
* `/closed [поиск]` (или `/done`) — **быстрый просмотр закрытых задач**:
  * отображает статус, дату и время закрытия, затраченное время;
  * кнопка **[♻️ Вернуть в работу]** — возвращает задачу в статус активных;
  * кнопка **[📋 Повторить задачу]** — создаёт новую активную задачу по образцу выполненной;
  * кнопка **[🗑 Удалить]** — окончательное удаление.
* `/now` — **анти-ступор**: быстрый выбор состояния (`🟢 Голова варит`, `🟡 Устал`, `🔴 Нет сил`) и выдача ровно 1 задачи с первым шагом на 10–15 минут.
* `/schedule_edit` — регулярная сетка недели:
  * просмотр расписания по дням (`Пн`–`Вс`);
  * массовый импорт по фото таблицы расписания, голосовому сообщению или тексту с предварительным подтверждением;
  * пауза сетки расписания (каникулы/больничный) до заданной даты.

### Память и контроль
* `/events` — разовые мероприятия, экзамены, олимпиады (контроль дедлайна регистрации и статуса).
* `/notes` — база знаний и заметок.
* `/find <запрос>` — полнотекстовый поиск FTS5 по заметкам, документам, а также активным и **закрытым задачам**.
* `/reminders` — персональные напоминания (с кнопками переноса на `+30 мин`, `+2 часа`).
* `/inbox` — история входящих сообщений с возможностью перезапуска сбойных элементов.
* `/status` — **статус сервера и моделей**: дашборд ПК (CPU, RAM, диск, аптайм, размер БД) и нейросетей (LLM пинг в мс, модели, Whisper STT в RAM, VLM, планировщик) с кнопкой **[🔄 Обновить]**.
* `/watch <url> <цель>` — мониторинг изменений веб-страницы по смысловому критерию.
* `/archive` — сводный архив: закрытые задачи, прошедшие события, поиск по архиву, очистка старых закрытых задач (>30 дней).
* `/stats` — подробная статистика выполнения дел: за сегодня, за неделю, за месяц, разбивка по категориям.

### Быстрый ввод
* `/task текст задачи` — мгновенное добавление дела без вызова нейросети.
* `/note текст заметки` — быстрое сохранение в базу знаний.
* `/remind 25.11 18:30 текст` — быстрое напоминание.
* Любой текст, голос, фото, файл или ссылка без слэша попадает в **умный Inbox**.

### Конфигурация и горячие настройки
* `/settings` (или `/setup`) — интерактивное inline-меню:
  * 📍 **Город и координаты** (автоматический геокодинг и часовой пояс через Open-Meteo).
  * 📅 **Регулярное расписание** и пауза сетки.
  * 📆 **Профили дней недели** (границы дня, режим дня: тяжёлый/средний/свободный, максимальное время блока задач).
  * ⏰ **Время утреннего брифинга** и **вечернего чек-ина**.
  * ⚡ **Питание ПК** (включение `rtcwake`, время подъёма и сна).
  * 🧠 **Модели:** выбор Whisper (`tiny`, `small`, `medium`, `large-v3-turbo`, `off`), тумблер VLM для изображений и редактирование контекстного профиля пользователя.
  * ⚡️ **Ход выполнения (Live Status):** гибкая настройка режима отображения промежуточных шагов выполнения (подробный / компактный / выключен) и тумблеры категорий (ссылки, аудио, документы, LLM, календарь).
  * 🖥 **Статус сервера:** быстрый переход в экран проверки ресурсов ПК и доступности моделей.
* `/cancel` — отмена текущего диалога ввода.

## 🔒 Безопасность и архитектурные гарантии (Guardrails)

1. **Глобальный семафор (`asyncio.Semaphore(1)`):** все ресурсоёмкие операции (вызовы LLM/VLM, транскрибация Whisper, рендеринг Chromium) выполняются строго по очереди. Это полностью исключает зависание и свопинг на ПК с умеренным объёмом RAM.
2. **Read-Only Zero-Trust Web:** веб-агент работает исключительно на чтение без возможности отправки форм или авторизации. Весь загружаемый веб-контент экранируется тегом `<untrusted_web_data>` с инструкцией игнорировать любые команды внутри веб-страниц (защита от Prompt Injection).
3. **Capture First:** входящие сообщения сначала персистятся в `inbox_log` со статусом `pending`. При сбое связи или перезагрузке ПК они остаются доступными в `/inbox` с кнопкой повтора.
4. **Контроль токенов:** во всех JSON-запросах передаётся `max_tokens=1200` и `enable_thinking: False`, что гарантирует быстрый роутинг и предотвращает исчерпание лимита токенов скрытыми блоками `<think>`.
5. **Один владелец:** бот защищён на уровне aiogram middleware и полностью игнорирует сообщения от посторонних пользователей.

## ❓ Частые вопросы и диагностика

* **`BOT_TOKEN is not set`:** скопируй `.env.example` в `.env` и вставь токен, полученный от `@BotFather`.
* **Долгая загрузка при старте:** бот опрашивает `GET {LLM_BASE_URL}/models` до 120 секунд. Это штатное поведение, необходимое для ожидания загрузки весов локальной модели с диска в VRAM/RAM.
* **Не разбираются фото:** убедись, что твоя локальная модель поддерживает зрение (VLM), и проверь в `/settings → Модели`, что переключатель VLM включён.
* **Ошибка Playwright:** выполни `playwright install chromium` (и `playwright install-deps chromium` на Linux).
* **Нет голосового распознавания:** убедись, что установлен пакет `faster-whisper`. При первом аудиосообщении веса скачиваются с Hugging Face автоматически.
